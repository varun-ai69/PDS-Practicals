## 1. Aim and Objectives

### Aim
To clean, impute, and preprocess structured web server access log records for downstream machine learning and threat classification by enforcing temporal validity (ISO-8601 UTC datetime), canonical missing value imputation, RFC 3986 URL path normalization, and whitespace standardization.

### Objectives
1. **Datetime Conversion & Standardisation:** Transform non-standard NCSA string timestamps (`[08/Oct/2026:08:15:32 +0000]`) into timezone-aware ISO-8601 UTC datetime objects (`datetime_utc`), deriving hour (`0–23`) and day-of-week (`0–6`) attributes.
2. **Missing Value Imputation:** Resolve missing and empty fields in `ident`, `auth_user`, `referrer`, `user_agent`, and `payload` using domain-grounded cybersecurity defaults (`"-"`, `"unknown"`, `""`).
3. **Data Consistency & Numeric Boundary Enforcement:** Validate numeric boundaries (`bytes_sent >= 0`, `status_code` within `[100, 599]`) and rectify anomalies.
4. **RFC 3986 URL Path Normalization:** Implement URL unquoting, lowercase path transformation, redundant slash collapsing (`//` $\rightarrow$ `/`), default index file canonicalization (`/index.html` $\rightarrow$ `/`), and query payload isolation.
5. **String Cleansing & Whitespace Rectification:** Strip leading/trailing whitespaces and collapse repeated internal spaces across all textual headers.
6. **Pipeline Continuity & Export:** Ingest Practical 2 structured tables and export preprocessed tabular datasets in CSV and Snappy-compressed Apache Parquet formats.
7. **External Real-World Benchmark:** Validate the end-to-end cleaning pipeline on Elastic's official production web server telemetry (10,000 real records).

## 2. Theoretical Architecture & Cleaning Principles

### 2.1 The Need for Normalization in Cybersecurity Data Science
Raw server logs capture heterogeneous HTTP requests generated by browsers, bots, security scanners, and network intermediaries. Without normalization:
- Path fragmentation occurs: `/store/index.php`, `/STORE/item/`, and `//store///item?id=1` would be treated as separate resources by statistical algorithms.
- Unhandled `NaN` values cause downstream machine learning models (Isolation Forest, Random Forest) to crash.
- Raw string timestamps prevent rolling window aggregations and burst velocity calculations ($\Delta t = t_i - t_{i-1}$) necessary for DDoS and brute-force detection.

### 2.2 Canonical Transformation Rules

| Field Name | Raw Uncleaned State | Preprocessing Transformation | Normalized State |
|---|---|---|---|
| `timestamp` | `08/Oct/2026:08:15:32 +0000` | Parse `%d/%b/%Y:%H:%M:%S %z`, forward-fill | `2026-10-08 08:15:32+00:00` (ISO UTC) |
| `ident` | `NaN`, `""` | Modern web servers omit RFC 1413 ident | `"-"` |
| `auth_user` | `NaN`, `""` | Unauthenticated public web traffic | `"-"` |
| `referrer` | `NaN`, `""` | Direct bookmarks, address bar entry, or scanners | `"-"` |
| `user_agent` | `NaN`, `""` | Unspecified client headers | `"unknown"` |
| `payload` | `NaN`, `""` | Static asset or route with no query parameters | `""` |
| `resource_requested` | `//STORE/index.html?id=45` | Unquote, lowercase, strip index, trim | Path: `/store`, URL: `/store?id=45` |
| `bytes_sent` | `< 0`, `NaN` | Non-negative integer boundary clipping | `0` (minimum bound) |
| `status_code` | Malformed / non-numeric | Numeric casting with standard fallback | `int16` in `[100, 599]` |
