           MODEL RETRAINING TELEMETRY & AUDIT REPORT (170,000 SAMPLES)

1. MOTIVATION & PROBLEM STATEMENT:
--------------------------------------------------------------------------------
While the academic models in Practical 9 achieved 99%+ accuracy on locked internal test sets,
real-world HTTP access traffic includes diverse benign telemetry (static CSS/JS assets, favicons,
short REST endpoints, modern Edge/Chrome User-Agents) that were absent in legacy training logs.
This caused a high False Alarm Rate (100% false positives on legitimate external requests).

2. DATASET AUGMENTATION STRATEGY:
--------------------------------------------------------------------------------
- Base Dataset     : Practical 6 SMOTE-balanced training partition (165,000 records).
- Diverse Telemetry: 5,000 live Apache access logs from Elastic production systems
                     (elastic_apache_access.log, HTTP 200 & 304 transactions).
- Total Ingestion  : 170,000 records (20,000 benign + 15,000 for each of 10 attack classes).
- Feature Vector   : 31 numerical features (30 lexical/entropy/behavioral + Isolation Forest score).

3. SERIALIZED RETRAINED ARTIFACTS:
--------------------------------------------------------------------------------
- outputs/models/random_forest_retrained_170k.joblib     : 53.09 MB (150 trees, max_depth=25, entropy)
- outputs/models/decision_tree_retrained_170k.joblib      : 134.88 KB (max_depth=20, min_split=5)
- outputs/models/logistic_regression_retrained_170k.joblib: 3.77 KB (StandardScaler + LogisticRegression)

4. REAL-WORLD BENCHMARK HIGHLIGHTS (225 UNSEEN REQUESTS):
--------------------------------------------------------------------------------
- Champion Model   : Random Forest Ensemble
- Attack Recall    : 138 / 145 (95.17% of all real attacks blocked)
- Benign Pass Rate : 80 / 80 (100.00% legitimate traffic passed without interruption)
- False Alarms     : 0 / 80 (0.00% False Positive Rate — Complete elimination of false alarms)
- Overall Accuracy : 96.89%
